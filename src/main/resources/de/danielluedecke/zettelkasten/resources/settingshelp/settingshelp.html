Help for Settings

This document provides help for items in the settings dialog of Thot+Amun which are not evident by their names and which are unsuitable for a tooltip.

General

Spell-checking while typing (edit-mode)

When this feature is enabled, an spell correction list is taken into account. The spell correction list can be opened via the ‘Edit’ button for entries. Example: Enter the three letters ‘teh’ under ‘Misspelled’ and ‘the’ under ‘Correct’. Finish editing by clicking in the line below the last entry and then clicking ‘Apply’ twice. Now, ‘teh’ will change to ‘the’ in the note field of the note editor when you press the space bar after typing.

Activate stenography

When this option is enabled, a steno list is taken into account. The steno list can be opened via the ‘Edit’ button for entries. Example: Enter the three letters ‘dna’ under ‘Steno word’ and ‘Deoxyribonucleic acid’ under ‘Original’. Finish editing by clicking in the line below the last entry and then clicking ‘Apply’ twice. Now, ‘dna’ will be converted to ‘deoxyribonucleic acid’ in the text field of the note editor when you press the Tab key after entering it.

Activat MarkDown

When enabled, formatting can be entered using MarkDown syntax in the note field of the note editor. The decision to enable MarkDown should be made at an early stage. Switching to the default UBB syntax may cause problems. MarkDown support in Thot+Amun is still under development. Enabling MarkDown is not currently recommended.

Fonts and Colours

Custom stylesheet for notes

When enabled, a stylesheet is used to define fonts, colours and spacing in the note view of the main window. The stylesheet can be opened in an editor window via the ‘Edit’ button. The entries now visible represent the current settings for fonts, colours and spacing. The entries are formatted in CSS notation, following the ‘Cascading Style Sheets’ model. Users with the relevant knowledge can edit the entries directly in the editor window and apply the changes by clicking the corresponding button. Alternatively, the entries can be changed using the buttons under ‘Fonts’ and ‘Other colour attributes’.

Custom stylesheet for outliner

When enabled, a stylesheet is used to define fonts, colours and spacing in the Desktop view. Settings are configured as described in the section ‘Custom stylesheet for notes’.

Directories

Path to attachments and Path to images

Here, you can specify directories for attachments and images for the currently Zettelkasten. Attachments and images can be copied or moved to these directories when they are attached to a note in this Zettelkasten. In this way, Thot+Amun will still be able to locate the attachments and images even if the Zettelkasten data file is moved to a different directory within the file system.

Path to pandoc

Thot+Amun exports notes to LibreOffice Writer and Microsoft Word file formats using the pandoc application. Here, you can specify the directory in which pandoc has been installed. This setting is important if Thot+Amun cannot find pandoc.

Hilfe zu den Einstellungen

Dieses Dokument bietet Hilfe zu Elementen im Einstellungsdialog von Thot+Amun, die nicht durch ihre Benennung klar sind und die sich nicht für einen Tooltip eignen.

Grundeinstellungen

Autokorrektur beim Tippen (Neueingabe von Zetteln)

Im aktivierten Zustand wird eine Autokorrekturliste berücksichtigt. Die Autokorrekturliste kann über den Knopf "Bearbeiten" für Eintragungen geöffnet werden. Beispiel: Tragen sie unter "Falsch" die drei Buchstaben "dsa" ein und unter "Richtig" "das". Beenden sie die Bearbeitung, indem sie in die Zeile unter dem letzten Eintrag klicken und dann zweimal auf "Übernehmen". Nun wird "dsa" zu "das" im Zettelfeld des Zettel-Editors, wenn sie nach der Eingabe auf die Leertaste drücken.

Steno-Funktion aktivieren

Im aktivierten Zustand wird eine Stenoliste berücksichtigt. Die Stenoliste kann über den Knopf "Bearbeiten" für Eintragungen geöffnet werden. Beispiel: Tragen sie unter "Abkürzung" die drei Buchstaben "dna" ein und unter "Original" "Desoxyribonukleinsäure". Beenden sie die Bearbeitung, indem sie in die Zeile unter dem letzten Eintrag klicken und dann zweimal auf "Übernehmen". Nun wird "dna" zu "Desoxyribonukleinsäure" im Zettelfeld des Zettel-Editors, wenn sie nach der Eingabe auf die Tabulatortaste drücken.

Markdown aktivieren

Im aktivierten Zustand können Formatierungen im Zettelfeld des Zettel-Editors in Markdown-Schreibweise eingegeben werden. Die Entscheidung über die Aktivierung von Markdown sollte früh getroffen werden. Ein Wechsel mit der voreingestellten UBB-Schreibweise kann zu Problemen führen. Die Unterstützung von Markdown durch Thot+Amun ist noch in Entwicklung. Die Aktivierung von Markdown wird derzeit nicht empfohlen.

Schriften und Farben

Eigenes Stylesheet für Zettel

Im aktivierten Zustand wird ein Stylesheet für die Festlegung von Schriften, Farben und Abständen in der Zettel-Ansicht des Hauptfensters verwendet. Das Stylesheet kann über den Knopf "Bearbeiten" in einem Editor-Fenster geöffnet werden. Die nun sichtbaren Einträge stellen die aktuellen Einstellungen für Schriften, Farben und Abstände dar. Die Einträge erfolgen nach Art der "Cascading Style Sheets" in CSS-Schreibweise. Sachkundige können die Einträge direkt im Editorfenster ändern und durch Klicken des entsprechenden Knopfs übernehmen. Alternativ können die Einträge über die Knöpfe bei "Schriftarten" und "Weitere Farbattribute" geändert werden.

Eigenes Stylesheet für Schreibtisch

Im aktivierten Zustand wird ein Stylesheet für die Festlegung von Schriften, Farben und Abständen in der Schreibtisch-Ansicht verwendet. Einstellungen erfolgen wie im Abschnitt "Eigenes Stylesheet für Zettel" beschrieben.

Verzeichnisse

Verzeichnis für Anhänge und Verzeichnis für Grafiken

Hier können Verzeichnisse für Anhänge beziehungsweise Grafiken für den aktuell geöffneten Zettelkasten festgelegt werden. Anhänge und Grafiken können in diese Verzeichnisse kopiert oder verschoben werden, wenn sie einem Zettel dieses Zettelkastens beigefügt werden. Auf diese Weise findet Thot+Amun die Anhänge und Bilder auch dann, wenn die Zettelkasten-Datei in ein anderes Verzeichnis im Dateisystem verschoben wird.

Verzeichnis für pandoc

Thot+Amun exportiert Zettel mit Hilfe der Anwendung pandoc in die Dateiformate von LibreOffice Writer und Microsoft Word. Hier kann das Verzeichnis festgelegt werden, in das pandoc installiert worden ist. Diese Einstellung ist dann von Bedeutung, wenn Thot+Amun pandoc nicht findet.
